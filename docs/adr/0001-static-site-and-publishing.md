网站用 Astro 将经校验的 Markdown 生成静态文件，部署到 GitHub Pages。页面、内容集合、语言地址和 CV 生成各自承担明确职责，类型从集合定义获得，不预建服务层。客户端只处理默认英文入口、移动导航、目录及轻微交互；内容在脚本失效时仍可阅读。

维护入口是 GitHub 仓库与拉取请求，不提供公网登录、写入接口或数据库。内容变更受仓库账号权限控制；站点不保存令牌、访客账号或表单资料。原始素材保留本地，公开输入只接受明确批准内容。Markdown 渲染剥离脚本、事件属性和危险地址；外部链接、日期、引用在构建时校验。私有输入和测试样例不能进入发布产物。

自动化检查使用只读仓库权限，只有发布任务获得 Pages 写入及短期身份令牌权限。正式部署仅上传通过校验的 dist，失败不触发上传与发布。GitHub Pages 不能执行服务端代码；未来确需内容编辑后台时，应另立需求与权限设计，不把密钥放入浏览器。
