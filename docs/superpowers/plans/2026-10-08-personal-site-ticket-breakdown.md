# 个人主页开发任务草案

状态：用户已授权按 implement-spec 实现和部署。规范与七项任务已发布到 GitHub Issues，编号和依赖见 `docs/implementation-issues.json`。本文件保留验收条件。

## 01：双语个人首页可完整浏览

**What to build:** 访客可以看到简介、照片和联系入口，在中英文间切换，在手机与键盘操作下正常浏览。

**Blocked by:** None (can start immediately)。

**Owner:** 页面基础与共享接口负责人。

- [ ] 首页遵循已选原型 A（基准 `7c20ee6`），个人标识为 `andy`；正式页面不包含风格切换条或示例内容。
- [ ] 首页和 404 可以从实际构建结果访问。
- [ ] 默认英文，记住手动语言选择，尊重指定语言链接。
- [ ] 禁止本地存储时切换仍可用；子目录部署时链接和图片正确。
- [ ] 只有批准的个人资料进入公开页面，原始素材和测试输出不进入公开构建。
- [ ] 桌面、手机、键盘及减少动态效果的检查通过。

## 02：Markdown 论文进入中英文成果列表

**What to build:** 维护者添加获准论文后，访客可以在两种语言的成果列表阅读正式信息和贡献说明，打开已有论文或代码链接。

**Blocked by:** 01：双语个人首页可完整浏览。

**Owner:** 学术成果负责人。

- [ ] 题名、作者、年份和状态准确，贡献说明完整双语。
- [ ] 未批准条目不显示；没有链接的按钮不显示。
- [ ] 修改 Markdown 后实际构建页面更新。
- [ ] 缺少必填信息或危险协议使构建失败并指出字段。

## 03：用户选定的项目进入中英文列表

**What to build:** 用户指定项目后，访客可以看到项目截图、用途与个人职责，并打开可用代码或演示。

**Blocked by:** 01：双语个人首页可完整浏览。

**Owner:** 个人项目负责人。

- [ ] 项目选择由用户决定，候选不能自动显示。
- [ ] 用途、职责和图片说明完整双语，手机端可读。
- [ ] 无可靠日期时不制造日期，没有外部链接时不出现空按钮。
- [ ] 修改内容后列表更新，无效内容明确阻止构建。

## 04：Blog 从 Markdown 到完整研究文章阅读

**What to build:** 访客可以浏览文章列表和独立阅读页，阅读公式、代码、图片与图注、目录、日期及标签；单语文章和已有译文都能正确访问。

**Blocked by:** 01：双语个人首页可完整浏览。

**Owner:** Blog 负责人。

- [ ] 两种界面包含相同的公开文章集合。
- [ ] 无译文时保留原文并标注语言，有译文时进入对应版本。
- [ ] 文章语言文件不相互覆盖，切换或刷新后内容身份不变。
- [ ] 长文章在手机上可读，只有必要的代码或公式局部滚动。
- [ ] 正文修改反映到实际页面，重复译文和错误日期能够检测。

## 05：首页精选与论文、项目、文章相互关联

**What to build:** 访客从首页重点作品进入完整列表和相关文章，再从文章返回关联的论文或项目，整个过程保留语言。

**Blocked by:** 02：论文列表；03：项目列表；04：Blog 阅读。

**Owner:** 内容整合负责人。

- [ ] 首页按已确认顺序展示用户指定的代表作品和最新文章。
- [ ] 首页不显示普通非精选条目、空精选区或测试占位。
- [ ] 正反向关联一致，无效或未公开关联会阻止构建。
- [ ] 从首页到文章再到关联作品的实际操作通过验收。

## 06：重新制作中英文 CV 并提供正确下载入口

**What to build:** 访客可以同时找到中文和英文 CV，打开重新排版的对应学术简历；维护者可以从源稿重新生成它们。

**Blocked by:** 01：双语个人首页可完整浏览。

**Owner:** CV 负责人。

- [ ] 两种 CV 白底单栏、结构对应，各以两页为目标，内容增加时自然延长。
- [ ] 只使用核对过的公开资料、公开链接成果和用户选定项目。
- [ ] 已有简历参考稿不冒充正式版；私人字段与未公开工作不进入正式 PDF。
- [ ] 中文与特殊字符正确，逐页渲染无裁切或溢出。
- [ ] 缺少某份最终 PDF 时没有无效入口；生成失败不破坏已有正式文件。

**External input:** 用户确认最终 CV 条目。

## 07：检查通过后才允许自动更新站点

**What to build:** 内容更新经过实际构建、浏览器和产物检查后才可发布；错误更新保留原有线上版本。

**Blocked by:** 05：首页与内容关联；06：正式中英文 CV。

**Owner:** 发布与验收负责人。

- [ ] 一次完整检查覆盖规范要求的访客行为和公开文件范围。
- [ ] 只有正式构建输出可上传，测试样例和本地素材被检测并排除。
- [ ] 子目录下的页面、图片、文章和 CV 链接全部有效。
- [ ] 校验失败时不触发部署，构建失败不更新线上版本。
- [ ] 用户确认部署目标后，以批准的内容更新验证发布全过程。
- [ ] 交付记录区分已验证、未验证及仍缺少的内容。

**External input:** 用户选择真实展示内容、确认正式地址并授权部署。
