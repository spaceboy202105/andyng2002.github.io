# Triage labels

本项目使用默认的五个分类标签。标签描述任务当前需要哪类处理；Issue 的打开或关闭状态及阻塞关系分别记录。

| Canonical role | Label in our tracker | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 需要维护者评估与分类 |
| `needs-info` | `needs-info` | 等待补充信息 |
| `ready-for-agent` | `ready-for-agent` | 描述充分，可由代理处理；开始前仍须检查前置任务 |
| `ready-for-human` | `ready-for-human` | 需要由人工实施 |
| `wontfix` | `wontfix` | 明确决定不处理 |

技能提到某个角色时，使用本表对应的标签字符串。已有同名标签直接复用；缺失时创建，不改动无关标签。
